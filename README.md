# 이날 (Inal) — 이야기가 있는 날씨

> **모바일 전용 날씨 조회·비교·이야기 웹서비스 (`https://inal.nuni.co.kr`)**  
> 1990년부터 쌓인 기상청 관측(ASOS)과 초단기실황·단기·중기예보를 바탕으로, 복잡한 통계 표 대신 **좌우로 넘기는 감성적인 날씨 카드**로 오늘과 과거의 날씨 이야기를 전합니다.

---

## 1. 빠른 시작 (개발 및 실행)

```bash
# 1. 환경변수 파일 준비
cp .env.example .env

# 2. 패키지 설치 및 개발 서버 실행 (읽기 전용 Weather API 프록시 자동 연동)
npm install
npm run dev

# 3. 프로덕션 빌드 및 운영 프록시 서버 실행
npm run build
npm run start

# 4. 자동 구조·프록시·결측치 규칙 검증 테스트
npm run verify
```

- 빌드 전에도 `public/mobile-preview.html`을 브라우저에서 바로 열면 4개 탭과 카드 스와이프, 지역 전환, 바텀시트 동작을 즉시 확인할 수 있습니다.

## 최근 비교·내 기준 배틀·절기/복날

- **오늘 첫 카드**: 어제 같은 정시·최근 7일 기온 비교, 펼치는 관측 그래프와 최고·최저 표.
- **이야기 → 날씨 배틀**: 어제·지난주·작년·직접 날짜, 최근 5년·10년·전체, 승리 조건 복수 선택. 항목별 양쪽 값과 승패 이유를 먼저 보여줍니다. 기존 상세 비교도 남아 있습니다.
- **이야기 → 절기·복날**: 관측소·연도를 고르고 복날·24절기를 주변 날씨와 비교합니다.
- 오늘·어제·최근7일은 동일 격자 초단기실황끼리 비교합니다. ASOS 장기/일자료와 분리 표기하며 예보·0으로 결측을 채우지 않습니다. [자료 제한과 계산 원칙](docs/WEATHER_CONTEXT.md).
- 새 회귀 테스트: `npm run test:context`. weather API를 먼저 적용해야 새 카드의 조회가 동작합니다. 운영 배포는 미리보기 승인 후 별도 진행합니다.

### 모바일은 핵심 정보만

inal은 지역·실황/예보 구분·시각, 주요 수치와 비교 결과, 배틀 항목별 양쪽 값/승패 이유, 이야기 결론과 핵심 그래프만 표시합니다. 출처·격자/지점 ID·표본수·계산/검증 설명·근거 상세 표/도움말은 렌더링하지 않습니다. 결측/잠정 결과 안내는 오해 방지를 위해 짧게 유지합니다. API 근거 필드는 그대로이며 weather WEB의 상세 표현에는 영향이 없습니다. `WeatherContextPanel`의 `showEvidence: false`가 모바일 전용 표현을 선택합니다.
