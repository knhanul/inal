# 기능 상태

## 동작

- 하단 네 메뉴, 헤더 지역·설정, 주소 해시(`#/today` 등)
- 지역 목록과 이 기기에 마지막 지역·비교 기간 저장
- 오늘: `/api/rt/now` 로 대표 카드, `/api/rt/today` 로 시간·짧은 이야기
- 예보: 시간별 가로 타임라인, 일별 목록, 중기 문장이 있으면 표시
- 비교: 올해 누적, 생활 질문, 기록, 지역 순위
- 이야기: `/api/rt/stories`, 날짜 조회, 어린이날·개천절 배틀
- 카드별 로딩·오류·다시 시도. 없는 값은 0 이나 맑음으로 채우지 않음
- 좌우 스와이프, 이전·다음, 점 표시
- PWA manifest 와 기존 로고

## 아직 얇은 부분

- 예보 바람 전용 API, 유사일 카드, 계절 신호 다섯 개의 단독 화면
- 배틀은 두 날짜를 임의로 고르는 편집 화면 없이, 어린이날·개천절 한 가지
- 질문 화면의 예문(생일, 비 오는 날 증가)은 API에 같은 문장이 있을 때만 이야기·생활 카드로 나옵니다. 문장을 만들지 않았습니다.
- 그래프 라이브러리는 넣지 않았습니다. 상세는 문장과 수치입니다.
